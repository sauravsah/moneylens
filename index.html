Welcome to MoneyLens

Three minutes, one time. MoneyLens turns the bank-alert emails your banks already send you into a live, private money dashboard.

  • Automatic: every new transaction lands by itself, within minutes of the alert.

Create your feed

This one script is the whole engine. It reads only bank-alert emails and serves them to this page.

  • Open script.google.com → New project.
  • Delete the sample code, paste the script below.
  • Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone.
  • Copy the Web app URL it gives you.

About Anyone: the web-app URL is an unguessable private key only you hold, and the script reads nothing but your own bank-alert emails.

Read bank SMS too (optional)

Email alerts sweep every 5 minutes. To also catch payments that only show up as an SMS on your phone, a tiny automation app forwards each bank SMS to your feed. Same script, same tracker. OTPs and promos are skipped automatically.

  • Install MacroDroid from the Play Store
  • Trigger: SMS received · sender Any
  • Action: HTTP POST · url = your feed URL · body = {sms_body} · content type Not set · follow redirects on
  • Bank alerts must arrive as real SMS: turn RCS off for your bank's chat
